# Customer Sales Analysis & Churn Prediction

An end-to-end data science project focused on cleaning, analyzing, aggregating, and visualizing customer sales transactions and churn metrics using Python and Pandas.

---

## Project Structure
```text
customer_analysis/
│
├── data/
│   ├── sales_data.csv
│   └── customer_churn.csv
│
├── notebooks/
│   └── customer_analysis.ipynb
│
├── outputs/
│   ├── charts/
│   │   ├── monthly_sales_trend.png
│   │   └── top_products.png
│   └── analysis_report.md
│
├── README.md
└── requirements.txt
Tech Stack & Libraries
Python (v3.13)

Pandas & NumPy (Data manipulation & aggregation)

Matplotlib & Seaborn (Data visualization)

Jupyter Notebook (Interactive development environment)

Key Analysis & Insights
Sales Trends: Analyzed monthly revenue trends to identify peak transaction periods.

Product Performance: Generated bar charts highlighting the top 5 best-selling products.

Customer Segmentation: Grouped data by customer ID and region using advanced pivot tables and aggregations to track high-value buyers.
